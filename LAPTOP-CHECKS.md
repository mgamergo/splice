# Laptop checks

Checks that can only run on the creator's laptop (Windows, Radeon 860M, RTX 5050). A PR that adds an entry under **Pending** gets the `needs-laptop` label and waits for the creator to verify and merge it. When a check passes, move it to **Verified** with the date and the commit it was verified on.

## Windows test run

Tested 2026-11-25 on `76d25e8c` with Windows 11, Git 2.55.0, Bun 1.2.18, FFmpeg and ffprobe 9.1, Chrome 158, and NVIDIA 610.74 (CUDA 13.3). Chrome used High performance on the RTX 5050 at the creator's request. The follow-up browser automation used T3 Code's integrated Chromium on the Radeon 860M and a separate browser project.

- `bun install --frozen-lockfile`, `bun run typecheck`, and `bun run build:web` passed. `bun run lint` reported 0 errors and 144 warnings.
- `bun test` finished with 701 passed, 3 skipped, 19 failed, and 4 errors. In this non-elevated Windows session, file symlink fixtures reported `EPERM: operation not permitted, symlink`. The setup failure also left `server` undefined in the footage route suite. See [`footage.test.ts`](apps/server/src/__tests__/footage.test.ts#L44), [`storage.test.ts`](apps/server/src/__tests__/storage.test.ts#L183), and [`transcription.test.ts`](apps/server/src/__tests__/transcription.test.ts#L250).
- The server tests write a `#!/bin/sh` fixture to `Tools/ffmpeg`, so Windows used `ffmpeg.exe` on PATH. The pause-scan tests reported `ffmpeg.exe exited with 183` and `Invalid data found when processing input` for a dummy `talk.wav`. Four hang-up tests expected a rejection and received a resolved promise. All six failures also reproduced with Bun 1.4.2. See [`server.test.ts`](apps/server/src/__tests__/server.test.ts#L131).
- The approval write and offline corrections tests reported `Quota exceeded`, `Transaction aborted`, or `Splice stopped` from their rejection mocks on Bun 1.2.18. Running just those two files yielded 23 passes, 3 failures, and 1 error on 1.2.18. All 26 passed on 1.4.2 on this laptop. See [`approval.test.ts`](apps/web/src/approval/__tests__/approval.test.ts#L190) and [`report-corrections.test.ts`](apps/web/src/bridge/__tests__/report-corrections.test.ts#L23).
